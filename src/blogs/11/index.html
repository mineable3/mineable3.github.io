Jail Breaking a Managed School Chrome Book

Enter Developer mode using ESC + Refresh + Power to get to system recovery, then do CTRL + d to enter developer mode

This will wipe all of your data, so back up anything you want to keep on a separate device. This is how you escape the device being managed. The Chrome Book 11 G5 EE (Education Edition) doesn’t allow running linux.

Then go to boot menu during manufacturer boot screen and boot from a linux USB Flash Drive

Use a partition software to delete all of the chrome OS partitions and create a blank file system

Run the Mr Chromebox firmware UEFI install script and install the new firmware

Boot again from linux USB and install normally from there
